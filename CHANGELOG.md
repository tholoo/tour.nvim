# Changelog

## Unreleased

Initial public version, targeting Neovim 0.13.

- Durable schema-v1 JSON tours with project-scoped progress and resume.
- Conceptual step navigation, a saved-tour library, and an overview picker.
- Virtual descriptions and above, below, inline, EOL, and highlight annotations.
- A range gutter that preserves other plugins' signs and custom statuscolumns.
- Literal anchor recovery and extmark tracking for edits during a tour.
- Non-mutating source inspection, snippet resolution, and whole-tour validation.
- Checked loading with source revisions and structured persistence/display results.
- Provider-agnostic authoring skill for existing Neovim MCP connections, preferring
  optional structured bridge tools with a command-based fallback.
- Authoring guidance to explicitly highlight every intended reading line per step.
- Loadable examples, Neovim help, JSON Schema, and a locked Nix development shell.
